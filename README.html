112 學年度大學部專題選題指南

本目錄依國立中央大學資訊工程學系「112 學年度大學部專題實驗競賽成果展」的 43 個題目整理。每一題各有一份 Markdown 文件，檔名即專題名稱；Windows 不允許的半形符號已改成相對應全形符號。

如何使用

  • 先看題目所屬組別與難度，再打開個別文件比較先備課程、風險與面談問題。
  • 每份文件均把必修課程拆成具體主題與選題前實作檢核，不應只用「修過課」判斷是否準備好。
  • 「擬議摘要」與「預期結論」是根據題名和研究設計新撰寫的草案；原始 PDF 未提供這兩項內容，因此草案不會虛構實驗數值或冒充原團隊文字。
  • 「詳細完成步驟」提供 16–18 週、10 階段的建議流程；涉及人體、醫療、特殊硬體或長期資料蒐集的題目通常需要更長時程。
  • 「具體研究工作、依賴與排程」把每題拆成 R01–R13 工作卡，列出主責角色、前置工作、交付物及可驗收的完成判定，可直接搬進專案看板。
  • 「指導教授最近五篇論文」按可核實的出版年份由新到舊列出，並附 DOI 或權威書目頁；共同指導題目會分別列出每位教授五篇。
  • 「事實」限於原始 PDF 與官方師資資料；題意、實作方式和難度均是依題名做的合理分析。
  • 這些是 112 學年度已完成的題目，不代表 115 學年度仍開放；選題前必須向教授確認目前題目與名額。
  • 教授背景查詢日期：2026-09-02。

共通課程準備

所有題目至少需要程式設計與資料結構。AI 類通常再需要線性代數、機率統計與機器學習；系統類通常再需要作業系統、計算機網路與軟體工程。中央大學資工系官方課程地圖亦將課程分為人工智慧／資料科學／多媒體、資安／網路／資料庫／系統、數位學習、軟體工程／計算理論等學群。
